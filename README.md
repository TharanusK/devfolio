# Tharanus Kongjaroon - Portfolio & CV

A modern, responsive personal portfolio and curriculum vitae website built with Next.js 16, standard Tailwind CSS, and shadcn/ui.

## Features

- **Modern Design**: Clean, responsive UI with Dark Mode support.
- **Dynamic Content**:
  - **Hero Section**: Welcoming introduction.
  - **Curriculum Vitae**: Detailed interactive timeline of work experience and education.
  - **Skills**: Categorized technical skills display.
  - **Contact**: Functional contact form with email integration.
- **Tech Stack**:
  - [Next.js 16](https://nextjs.org/) (App Router)
  - [Tailwind CSS](https://tailwindcss.com/)
  - [shadcn/ui](https://ui.shadcn.com/) components
  - [Resend](https://resend.com/) for email functionality
  - [Lucide React](https://lucide.dev/) for icons

## Getting Started

### Prerequisites

- Node.js 18+ installed
- A [Resend](https://resend.com) API key for the contact form
